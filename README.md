# 🪟 WinToMac (WinBridge) ➔ macOS

> **Ультимативная нативная утилита для комфортного перехода с Windows на macOS.**  
> Делает из macOS дружелюбную систему: возвращает привычные горячие клавиши, поведение Проводника, буфер обмена `Win + V` с поддержкой картинок, переключение языка на `Alt + Shift`, `Alt + F4` и виндовый Snap окон.

## ✨ Возможности

### 1. ⌨️ Клавиатура и текст
* **`Ctrl + Backspace`** — удаляет ровно одно слово назад (а не всю строку, как в Mac по умолчанию). Работает везде: в Chrome, Discord, VS Code, Telegram, Safari, Obsidian и т.д.
* **`Ctrl + Delete`** — удаляет слово вперед.
* **`Ctrl + Стрелки (влево/вправо)`** — прыжки курсора по словам, а с `Shift` — выделение слов.
* **`Home` / `End`** — мгновенный переход в начало/конец строки (с `Ctrl` — в начало/конец документа).
* **`Win + Shift + S`** (Ножницы) — выделение области экрана прямо в буфер обмена.
* **`Alt + Shift` / `Ctrl + Shift`** — мгновенная смена раскладки клавиатуры без лагов.
* **`Alt + F4`** — честное закрытие и выгрузка активного приложения (как `Cmd + Q`).

### 2. 📋 Продвинутый буфер обмена (`Win + V`)
* **Всплывающий HUD по `Win + V`** с поддержкой **текста и картинок** (скриншоты сохраняются с превью!).
* **Быстрая вставка:** клик мышкой, клавиша `Enter` (последний элемент) или цифры `1..9` на клавиатуре.
* **Булавка 📌 (Pinned):** закрепляйте важные пароли, ссылки и шаблоны — они никогда не удалятся при очистке истории.
* **Большой менеджер в главном окне:** поиск по истории, предпросмотр текста и картинок, счетчик символов.
* **Энергонезависимость:** история сохраняется на диск и восстанавливается после перезагрузки.

### 3. 🪟 Окна и многозадачность
* **Виндовый Snap окон (`Win + Стрелки`):**
  * `Win + Влево` — примагнитить окно к левой половине экрана.
  * `Win + Вправо` — к правой половине экрана.
  * `Win + Вверх` — развернуть окно на весь экран (Maximize).
  * `Win + Вниз` — вернуть окну прежний размер по центру (Restore).
* **Виндовый `Alt + Tab`** — быстрое переключение между открытыми окнами с превью.
* **Глобальные шорткаты:**
  * `Win + E` — открыть Проводник (Finder на домашней папке).
  * `Win + D` — свернуть все окна и показать рабочий стол.
  * `Win + L` — заблокировать экран.
  * `Ctrl + Shift + Esc` — открыть Диспетчер задач (*Мониторинг системы*).

### 4. 📂 Проводник (Finder)
* **`Enter`** — открывает файл/папку (вместо переименования).
* **`F2`** — переименовывает файл.
* **`Delete` (Del)** — отправляет выбранный файл в корзину без лишних диалогов.
* **`Backspace`** — переходит на уровень выше (на папку вверх).
* **`Ctrl + H`** — показывает или прячет скрытые файлы с точкой.

### 5. 🖱 Мышь и скролл
* **Раздельный скролл (Windows Scroll):** инвертирует направление колесика мыши, оставляя естественный скролл на трекпаде нетронутым.
* **Линейная мышь:** отключает акселерацию курсора macOS для максимальной точности 1:1.

### 6. 🖥 Архитектура Dual UI (Окно + Трей + Dock)
* Красивое нативное окно на **SwiftUI** с боковым меню.
* Иконка в Dock и в строке меню (Menu Bar).
* При закрытии окна на крестик `[x]` программа автоматически убирает значок из Dock и продолжает тихо работать в фоне в трее.

## 🛠 Сборка и запуск

### Требования
* macOS 13.0 (Ventura) или новее.
* Swift 6.0+ (Command Line Tools: `xcode-select --install`).

### Сборка из исходников
```bash
git clone https://github.com/<your-username>/<repo-name>.git
cd <repo-name>

# Сборка, подпись и установка в /Applications/
./build_app.sh
```

## 🔒 Безопасность и разрешения (TCC)
Для перехвата и подмены модификаторов приложение использует системный `CGEventTap`.  
При первом запуске разрешите доступ в:
**Системные настройки ➔ Конфиденциальность и безопасность ➔ Универсальный доступ ➔ WinToMac (Вкл)**.
