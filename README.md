# 🪟 WinBridge ➔ macOS

> **Ультимативная нативная утилита для комфортного перехода с Windows на macOS.**  
> Возвращает привычную мышечную память Windows: горячие клавиши, поведение Проводника, буфер обмена `Win + V` с поддержкой картинок, нативный переключатель окон `Alt + Tab`, закрытие программ по `Alt + F4`, переключение языка на `Alt + Shift` и виндовый Snap окон.

## ✨ Возможности WinBridge

### 1. 🪟 Переключение окон (Windows Alt + Tab)
* **Встроенный нативный переключатель `Alt + Tab`:** всплывающий HUD в стиле Windows 11 с карточками запущенных приложений в актуальном Z-порядке (MRU).
* Удерживайте `Alt` и нажимайте `Tab` для выбора, отпустите `Alt` — окно мгновенно активируется.
* Поддержка `Shift + Tab` и стрелок влево/вправо для навигации, `Esc` для отмены.
* Опциональная интеграция с внешним **AltTab** (для пользователей, желающих миниатюры содержимого окон).

### 2. ⌨️ Клавиатура и текст
* **`Ctrl + Backspace`** — удаляет ровно одно слово назад (а не всю строку, как в Mac по умолчанию). Работает везде: в Chrome, Discord, VS Code, Telegram, Safari, Obsidian и т.д.
* **`Ctrl + Delete`** — удаляет слово вперед.
* **`Ctrl + Стрелки (влево/вправо)`** — прыжки курсора по словам, а с `Shift` — быстрое выделение слов.
* **`Home` / `End`** — мгновенный переход в начало/конец строки (с `Ctrl` — в начало/конец документа).
* **`Win + Shift + S`** (Ножницы) — интерактивное выделение области экрана прямо в буфер обмена.
* **`Alt + Shift` / `Ctrl + Shift`** — мгновенная смена раскладки клавиатуры без лагов.
* **`Alt + F4`** — честное завершение активного приложения (как `Cmd + Q`, либо `Cmd + W` для вкладок Finder).

### 3. 📋 Продвинутый буфер обмена (`Win + V`)
* **Всплывающий HUD по `Win + V`** с поддержкой **текста и картинок** (скриншоты сохраняются с превью!).
* **Быстрая вставка:** клик мышкой или выбор с клавиатуры.
* **Булавка 📌 (Pinned):** закрепляйте важные пароли, сниппеты и ссылки — они сохраняются даже при очистке истории.
* **Менеджер в главном окне:** поиск по истории, предпросмотр текста и картинок.
* **Энергонезависимость:** история сохраняется на диск и восстанавливается после перезагрузки.

### 4. 🪟 Окна и многозадачность (Snap)
* **Виндовый Snap окон (`Win + Стрелки`):**
  * `Win + Влево` — примагнитить окно к левой половине экрана.
  * `Win + Вправо` — к правой половине экрана.
  * `Win + Вверх` — развернуть окно на весь экран (Maximize).
  * `Win + Вниз` — вернуть окну прежний размер по центру (Restore).
* **Глобальные шорткаты:**
  * `Win + E` — открыть Проводник (Finder на домашней папке).
  * `Win + D` — свернуть все окна и показать рабочий стол.
  * `Win + L` — заблокировать экран.
  * `Ctrl + Shift + Esc` — открыть Диспетчер задач (*Мониторинг системы*).

### 5. 📂 Проводник (Finder)
* **`Enter`** — открывает файл/папку (вместо переименования).
* **`F2`** — переименовывает файл.
* **`Delete` (Del)** — отправляет выбранный файл в корзину без лишних диалогов.
* **`Backspace`** — переходит на уровень выше (на папку вверх).
* **`Ctrl + H`** — показывает или прячет скрытые файлы.

### 6. 🖱 Мышь и скролл
* **Раздельный скролл (Windows Scroll):** инвертирует направление колесика дискретной мыши, оставляя естественный скролл на трекпаде нетронутым.
* **Линейная мышь:** отключает акселерацию курсора macOS для максимальной точности 1:1.

### 7. 🖥 Архитектура Dual UI (Окно + Трей + Dock)
* Нативное окно на **SwiftUI** с боковым меню и полными настройками.
* Иконка в Dock и в строке меню (Menu Bar).
* При закрытии окна на крестик `[x]` программа автоматически убирает значок из Dock и продолжает тихо работать в фоне в трее.

## 🛠 Сборка и запуск

### Требования
* macOS 13.0 (Ventura) или новее.
* Swift 6.0+ (Command Line Tools: `xcode-select --install`).

### Сборка из исходников
```bash
git clone https://github.com/<your-username>/winbridge.git
cd winbridge

# Сборка, подпись и установка в /Applications/
./build_app.sh
```
